# Vietnam-Thailand-2027-Pro

אתר טיול סטטי מוכן ל-GitHub Pages.

## העלאה
1. צור Repository חדש בשם `Vietnam-Thailand-2027-Pro`.
2. העלה את כל הקבצים והתיקיות שבתיקייה זו לשורש המאגר.
3. Settings > Pages > Deploy from a branch > main > /(root).
4. המתן לסימון הירוק ב-Actions.

## חשוב
- אין צורך ב-Waze.
- לחיצה על כל כפתור יום מובילה לעמוד היום.
- ימי מדריך מודגשים בצבע.
- Leaflet CSS מוטמע מקומית כדי למנוע אריחי מפה מפוזרים.
- Leaflet JavaScript ואריחי OpenStreetMap נטענים מהאינטרנט.
