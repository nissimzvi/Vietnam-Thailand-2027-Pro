## העלאה
1. GitHub → repository `Vietnam-Thailand-2027-Pro` → Code.
2. Add file → Upload files.
3. לגרור את כל הקבצים מתוך התיקייה הזו (index.html, day01...day25, assets, .nojekyll וכו').
4. Commit changes ישירות ל-main.
5. להמתין ל-Actions / GitHub Pages לסימון ירוק.
6. לפתוח את האתר ולעשות Ctrl+F5.
